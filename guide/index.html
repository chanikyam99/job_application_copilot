Each code file has a Copy button. Create the file at the path shown in the header, paste the code, done.

What You Are Building

A full-stack AI app where a user uploads their resume + pastes a job description and receives 4 tailored artifacts generated by 4 LLM agents running in parallel:

🎯
Fit Analysis

Match score 0–100, requirements met/missing, key JD keywords

📝
Resume Rewrite

Same role list, stronger bullets, JD keywords woven in, diff view

✉️
Cover Letter

1 page, tone-matched, downloadable as .docx

🎤
Interview Prep

10 questions with STAR answers grounded in your resume

Complete File Structure

job-copilot/
  backend/
    ✓ main.py — FastAPI app entry point + CORS
    ✓ database.py — SQLAlchemy engine + session
    ✓ models.py — User, Application, Draft ORM models
    ✓ schemas.py — Pydantic v2 request/response schemas
    ✓ auth.py — JWT encode/decode + password hashing
    ✓ requirements.txt
    ✓ .env — your real secrets (never commit)
    ✓ .env.example — template (safe to commit)
    agents/
      ✓ __init__.py
      ✓ orchestrator.py — 4 LLM agents + asyncio.gather()
    routers/
      ✓ __init__.py
      ✓ auth_router.py — signup, login, /me
      ✓ applications_router.py — CRUD + generate + download
    utils/
      ✓ __init__.py
      ✓ pdf_parser.py — pypdf text extraction
      ✓ docx_generator.py — python-docx cover letter

  frontend/
    ✓ index.html — login / signup page
    ✓ dashboard.html — applications list + stats
    ✓ new-application.html — 3-step create + generate
    ✓ application.html — 4-tab artifact viewer
    css/
      ✓ main.css — full design system
    js/
      ✓ api.js — central fetch wrapper + auth + toasts
