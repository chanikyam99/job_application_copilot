Slide Deck Outline

A 12–15 slide PPT outline for the capstone presentation. Includes an AI prompt you can paste into Gamma or ChatGPT to generate a starting draft.

Font: Inter (matches the app). Heading weight: 700–800. Body weight: 400–500. Keep slides sparse — screenshots carry the weight. One key point per slide maximum.

Gamma / ChatGPT Prompt — Generate a Draft Deck

Paste this into Gamma (gamma.app → New → Generate with AI) or ChatGPT to get a starting slide deck you can then edit:

AI slide generation prompt — paste into Gamma or ChatGPT 
You are a presentation designer. Create a 12-slide PowerPoint outline for a capstone project called "Job Application Co-Pilot".

Project summary:
- Full-stack web app built with FastAPI (backend) and vanilla HTML/CSS/JS (frontend)
- Users upload a resume PDF and paste a job description
- Four AI agents run in parallel using Groq's LLaMA 3.3 70B model to generate:
  1. A fit analysis with a match score and skill gap breakdown
  2. A rewritten resume with JD keywords injected via side-by-side diff
  3. A personalised cover letter (downloadable as .docx)
  4. 10 interview Q&As with sample answers and coaching tips
- Backend deployed on Render with PostgreSQL; frontend on Netlify
- Auth: JWT tokens stored in localStorage, bcrypt password hashing
- Key innovation: parallel agent execution cuts generation time from ~45s to ~15s

Slides to cover (in order):
1. Title — project name, tagline, name/date
2. Problem — time cost of tailoring job applications; most applicants get no response
3. Solution — one upload, four AI artifacts, 30 seconds
4. Tech Stack — FastAPI, SQLAlchemy, Alembic, Groq (LLaMA 3.3 70B), PostgreSQL, Vanilla JS, Netlify, Render
5. Architecture diagram — Browser → Netlify → Render (FastAPI) → PostgreSQL → Groq API
6. Agent Pipeline — 4-stage flow with parallel execution timing (show 3× speedup)
7. Demo: Dashboard — stat cards, filter by status, app card grid
8. Demo: New Application Wizard — 3-step wizard, PDF drop, progress screen
9. Demo: Fit Analysis — score ring, matched/missing requirements, keyword pills
10. Demo: Resume & Cover Letter — diff view + .docx download
11. Demo: Interview Prep — accordion Q&A with sample answers
12. Deployment — Render + PostgreSQL (backend) / Netlify (frontend)
13. Key Engineering Decisions — table comparing decision vs alternative vs reason
14. Challenges & Learnings — 3-4 bullets
15. What's Next + Close — future features + closing line

Use a dark theme (#0f172a background, #3b82f6 accent, Inter font). Keep each slide to one key point with a supporting visual or diagram description. Output as a structured markdown outline with slide numbers, headings, bullet points, and visual descriptions.
