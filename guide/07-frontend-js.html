Section 07

Frontend JavaScript

One shared module (api.js) handles all HTTP calls, authentication state, and UI helpers. Every page imports from it.

Overview

api.js is an ES Module — imported with <script type="module"> on each page. It exports: the auth object (token/user storage), the api object (HTTP methods), helper functions (toast, showLoading, hideLoading, requireAuth, formatDate, statusLabel, statusDot). This means all API calls go through one place — if the backend URL changes, you update one line.

1 · BASE_URL and auth object

WHY BASE_URL and auth

BASE_URL in one place means changing localhost:8000 to a production URL is a 1-line edit. The auth object wraps localStorage access — if you later switch to sessionStorage or cookies, only this object changes. getUser() uses JSON.parse because localStorage only stores strings; setUser() uses JSON.stringify for the same reason.

2 · The request() function — core fetch wrapper

WHY one request() function

Every HTTP call goes through one request() function. This means:

  1. The Authorization: Bearer <token> header is added automatically — you never forget it.
  2. 401 Unauthorized redirects to login automatically — no per-endpoint handling.
  3. 204 No Content returns null (fetch would error if you tried to parse empty body as JSON).
  4. Error messages from the backend (detail field in FastAPI's default error format) are extracted and thrown — so callers can catch(err) { showError(err.message) }.

3 · HTTP method shortcuts

WHY method shortcuts

api.get('/applications/') is cleaner than request('GET', '/applications/') every time. postForm exists specifically for file upload endpoints — the body must be FormData (multipart/form-data), not JSON. Passing isFormData = true tells request() not to set Content-Type (the browser sets the correct multipart boundary automatically).

4 · Toast notifications

WHY toasts instead of alert()

Non-blocking feedback. The user submits a form → the toast appears for 3 seconds and fades without interrupting the flow. Blocking alert() stops execution and requires clicking OK — bad UX for async operations. Three types: success (green), error (red), info (blue).

5 · Loading overlay

WHY a loading overlay

AI generation takes 15–30 seconds. Without a loading state, users don't know if the request is processing or stuck. The overlay covers the full screen with a spinner and message, preventing double-submissions. showLoading(msg) accepts a custom message so "Generating your kit..." differs from "Regenerating cover letter...".

6 · Utility helpers

WHY centralized utility helpers

formatDate converts ISO timestamps from the backend into readable "Jun 17, 2025" format. statusLabel and statusDot map backend enum values (not_yet, applied, etc.) to display strings and color dots — centralizing this mapping means updating it in one place changes all pages simultaneously.

How pages import from api.js

Every HTML page that needs API access uses <script type="module"> to import from api.js. The type="module" attribute is required — without it, browsers do not support import/export syntax and will throw a SyntaxError. Module scripts also get two automatic behaviors: they are deferred (the script runs after the DOM is fully loaded, so document.getElementById() calls always succeed), and they execute in strict mode (catching common bugs like undeclared variables).
