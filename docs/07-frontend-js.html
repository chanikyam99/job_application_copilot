Section 07

Frontend JavaScript

Two shared JS files power all HTTP calls, environment configuration, authentication state, and UI helpers. Every page uses both.

Overview

config.js is a plain script that sets window.BACKEND_URL based on the current hostname — it must load before api.js. api.js is an ES Module — imported with <script type="module"> on each page. It exports: the auth object (token/user storage), the api object (HTTP methods including getBlob for file downloads), and helper functions (toast, showLoading, hideLoading, requireAuth, formatDate, statusLabel, statusDot). All API calls go through one place — if the backend URL changes, you update one file.

config.js — Environment-Aware Backend URL

WHY config.js exists as a separate plain script

config.js sets window.BACKEND_URL based on location.hostname. When the hostname is localhost, 127.0.0.1, or empty (file:// protocol), it points to the local dev server. Any other hostname (your deployed Vercel/Netlify/etc. domain) gets the production Render backend URL.

It must load as a plain <script> in every HTML page's <head> before the ES module api.js. This is because api.js reads window.BACKEND_URL on line 4 at module evaluation time — if config.js has not run yet, window.BACKEND_URL is undefined and the fallback http://localhost:8000 is used even in production.

After deploying to Render, open frontend/js/config.js and replace https://YOUR_BACKEND.onrender.com with your actual backend service URL.

1 · BASE_URL and auth object

WHY BASE_URL reads window.BACKEND_URL

BASE_URL is set from window.BACKEND_URL (populated by config.js) with a fallback to http://localhost:8000 for safety. This means changing the backend URL never requires editing api.js — only config.js. The auth object wraps localStorage access — if you later switch to sessionStorage or cookies, only this object changes. getUser() uses JSON.parse because localStorage only stores strings; setUser() uses JSON.stringify for the same reason.

2 · The request() function — core fetch wrapper

WHY one request() function

Every HTTP call goes through one request() function. This means:

  1. The Authorization: Bearer <token> header is added automatically — you never forget it.
  2. 401 Unauthorized redirects to login automatically — no per-endpoint handling.
  3. 204 No Content returns null (fetch would error if you tried to parse empty body as JSON).
  4. Error messages from the backend (detail field in FastAPI's default error format) are extracted and thrown — so callers can catch(err) { showError(err.message) }.

3 · HTTP method shortcuts and getBlob()

WHY method shortcuts

api.get('/applications/') is cleaner than request('GET', '/applications/') every time. postForm exists specifically for file upload endpoints — the body must be FormData (multipart/form-data), not JSON. Passing isFormData = true tells request() not to set Content-Type (the browser sets the correct multipart boundary automatically).

WHY getBlob() is needed alongside get()

The regular get() method calls res.json() which fails on binary content — calling .json() on a .docx or .txt file response throws a parse error. getBlob() skips the JSON parse entirely and returns the raw Blob so the caller can create an object URL (URL.createObjectURL(blob)) and trigger a browser download. It is needed for both the cover letter .docx and the resume .txt download endpoints.

4 · Toast notifications

WHY toasts instead of alert()

Non-blocking feedback. The user submits a form → the toast appears for 3 seconds and fades without interrupting the flow. Blocking alert() stops execution and requires clicking OK — bad UX for async operations. Three types: success (green), error (red), info (blue).

frontend/js/api.js javascript

5 · Loading overlay

WHY a loading overlay

AI generation takes 15–30 seconds. Without a loading state, users don't know if the request is processing or stuck. The overlay covers the full screen with a spinner and message, preventing double-submissions. showLoading(msg) accepts a custom message so "Generating your kit..." differs from "Regenerating cover letter...".

6 · Utility helpers

WHY centralized utility helpers

formatDate converts ISO timestamps from the backend into readable "Jun 17, 2025" format. statusLabel and statusDot map backend enum values (not_yet, applied, etc.) to display strings and color dots — centralizing this mapping means updating it in one place changes all pages simultaneously.

How pages import from api.js

Every HTML page that needs API access must first load config.js as a plain script in <head>, then use <script type="module"> to import from api.js. The type="module" attribute is required — without it, browsers do not support import/export syntax and will throw a SyntaxError. Module scripts also get two automatic behaviors: they are deferred (the script runs after the DOM is fully loaded, so document.getElementById() calls always succeed), and they execute in strict mode (catching common bugs like undeclared variables).
