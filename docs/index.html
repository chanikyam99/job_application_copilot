Ultimate Guide

Job Application Co-Pilot

One complete guide — build, fix, deploy, and present. 14 sections covering every file in the codebase, with code examples verified against the actual source.

What You're Building

A full-stack AI web app that takes a resume PDF and a job description, runs four LLM agents in parallel, and produces a complete application kit in under 30 seconds.

AgentOutputTime
Fit AnalystMatch score (0–100%), matched requirements, skill gaps, JD keywords~8s
Resume WriterBullet-by-bullet rewrite with JD keywords injected, side-by-side diff~12s (parallel)
Cover Letter WriterOne-page targeted cover letter, downloadable as .docx~10s (parallel)
Interview Coach10 Q&A pairs — behavioral, technical, situational — with sample answers and coaching tips~15s (parallel)

Tech Stack

LayerTechnologyWhy
Backend APIFastAPI (Python)Auto-generates Swagger docs, async support, type-safe with Pydantic
ORMSQLAlchemy + AlembicType-safe queries, schema migrations
DatabaseSQLite (local) → PostgreSQL (production)Zero-config local dev; production-grade cloud DB
AI / LLMGroq API — LLaMA 3.3 70B VersatileFree tier, low latency, structured JSON output
AuthJWT (python-jose) + bcryptStateless — scales without server session storage
File handlingpypdf + python-docxPDF text extraction; .docx generation
FrontendVanilla HTML + CSS + JavaScript (ES modules)No build step, no framework — deploys by dropping a folder on Vercel
IconsLucide Icons CDNNo npm required, consistent SVG icon set
Backend deployRender (Web Service + PostgreSQL)Free tier, GitHub auto-deploy, managed DB add-on
Frontend deployVercel (static site)Free, GitHub-connected, instant CDN
