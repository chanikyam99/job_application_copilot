Create a 10-slide minimalistic PowerPoint presentation for a project called "Job Application Co-Pilot".

Design rules:
- White background (#ffffff), blue accent (#2563eb), dark text (#0f172a)
- Font: Inter or Calibri. Max 3 bullet points per slide.
- One key message per slide. Clean and sparse — no decorations.
- 16:9 widescreen format.

Project overview:
- Full-stack web app: FastAPI backend + vanilla HTML/CSS/JS frontend
- Users upload a resume PDF and a job description
- 4 AI agents run in parallel via Groq (LLaMA 3.3 70B) to generate:
  1. Fit Analysis — match score, skill gaps, JD keywords
  2. Resume Rewrite — tailored bullets, side-by-side diff view, .docx download
  3. Cover Letter — personalised one-pager, .docx download
  4. Interview Prep — 10 Q&As with sample answers and coaching tips
- Backend: Render (Web Service + PostgreSQL). Frontend: Vercel.
- Auth: JWT tokens + bcrypt. Migrations: Alembic.
- Parallel execution cuts generation time from ~45s to ~15s (3× speedup).

10 slides in this exact order:
1. Title — "Job Application Co-Pilot" / tagline: "From Resume to Interview-Ready in 30 Seconds" / your name and date
2. The Problem — 3 pain points: hours per tailored application, low response rates, unprepared interviews
3. The Solution — 1 upload, 4 AI artifacts, 30 seconds. Show the 4 output types.
4. Tech Stack — Backend (FastAPI, PostgreSQL, Groq), Frontend (Vanilla JS), Infrastructure (Render, Vercel)
5. Architecture — Browser → Vercel → Render (FastAPI) → PostgreSQL + Groq API. Highlight JWT auth and parallel pipeline.
6. Agent Pipeline — Fit Analyst runs first; Resume Writer + Cover Letter Writer + Interviewer run in parallel. Show 3× speedup stat.
7. Demo: Fit Analysis — Match score ring, matched requirements (green), gaps (red), keyword extraction
8. Demo: Resume & Cover Letter — Side-by-side diff view, download .docx resume, cover letter preview
9. Demo: Interview Prep — 10 accordion Q&As, sample answers, coaching tips
10. Engineering Decisions & What's Next — 3 key decisions (Groq over OpenAI, parallel execution, SQLite→PostgreSQL toggle) + 2 future features

Output as a structured markdown outline with slide numbers, one-line headlines, 2–3 bullet points, and a short visual description per slide.

asyncio.gather() runs the three remaining agents concurrently. Wall-clock time is the slowest of the three, not the sum.
